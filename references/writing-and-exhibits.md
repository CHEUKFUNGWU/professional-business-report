# Writing and exhibits

For English output, apply [language-and-style.md](language-and-style.md) alongside this reference.

## Build the argument first

Write one governing thought and three to seven supporting claims before drafting. Arrange sections as an argument, not as a diary of research steps.

Common narrative shapes:

- puzzle -> evidence -> explanation -> decision;
- performance gap -> drivers -> root causes -> action;
- market change -> opportunity -> capability gap -> choice;
- baseline -> variant view -> drivers -> scenarios -> implications;
- current state -> options -> trade-offs -> recommendation -> implementation.

## Answer-first hierarchy

Each level should make a supported claim:

- the title captures the conclusion or real tension;
- the executive summary gives the answer and why it matters;
- section titles state findings;
- exhibit titles state the takeaway;
- the first sentence of a paragraph states its point.

Do not use a tension-rich title unless both sides are important and evidenced. Clarity beats wordplay.

## Executive summary

The summary should stand alone. Include:

1. the decision context;
2. the governing answer;
3. the few facts or estimates that carry the conclusion;
4. the mechanism or source of the difference;
5. the main implication, choice, or action;
6. the largest uncertainty or condition that would change the view.

Do not introduce numbers that the body does not support.

## Analytical paragraphs

Use this sequence when it fits:

`claim -> evidence -> explanation -> qualification -> implication`

One paragraph should carry one main point. Name the source or method instead of writing "research shows." Use active voice and concrete verbs. Delete sentences that could appear unchanged in any report.

## Quantitative prose

- Put the value, comparison, period, and denominator together.
- State whether a number is actual, estimated, forecast, reported, or modelled.
- Use percentage points for differences between percentages.
- Explain multiples in plain language.
- Distinguish annual average, period end, cumulative change, CAGR, and contribution.
- Keep rounding consistent and reconcile totals.
- Lead with a few load-bearing numbers, not every output produced.

## Exhibits

Every material chart or table needs:

- an assertion title;
- measure, unit, geography, period, and sample or population;
- clear actual, benchmark, target, forecast, and scenario labels where applicable;
- direct source attribution;
- a note for definitions, exclusions, calculations, proxies, and limitations.

Choose the display from the analytical question:

- line chart for change over time;
- bar or dot plot for comparison;
- scatterplot for relationships;
- distribution plot for spread and outliers;
- waterfall for reconciled contributions;
- matrix for prioritisation;
- map for a value chain, ecosystem, or process;
- table for exact values and forecasts;
- timeline for dependent actions.

Do not repeat the same data in prose, chart, and table unless each serves a different purpose.

## Cases and quotations

Write cases as context, intervention, result, mechanism, and transferability. Use quotations only when the speaker's wording adds insight. Quotes supplement evidence; they do not replace it.

## Recommendations

Write recommendations as choices, not slogans. State:

- what should change;
- which evidence supports it;
- expected value or outcome;
- owner and prerequisite;
- sequence and decision gate;
- trade-off and risk;
- leading and outcome measures.

## Style

Write for an informed, impatient reader. Be confident where evidence is strong and explicit where it is weak. Use the professional business register, grammatical control, and precise advanced vocabulary defined in [language-and-style.md](language-and-style.md).

Avoid:

- promotional adjectives and unsupported superlatives;
- vague attribution;
- repetitive "not only X but also Y" constructions;
- forced lists of three;
- decorative acronyms;
- abstract consulting terms when a plain word exists;
- long scene-setting introductions;
- generic endings such as "the future is promising";
- claims that correlation proves cause.

Use the language, citation style, headings, word limit, and section structure set by the governing brief.
